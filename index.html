⚙️ Configuration requise

Cette application a besoin d'un projet Firebase gratuit pour que les utilisateurs partagent leurs données. Les identifiants Firebase (FIREBASE_CONFIG) n'ont pas encore été renseignés dans le fichier.

Ouvrez le fichier HTML dans un éditeur de texte, cherchez const FIREBASE_CONFIG près du début du script, et remplacez les valeurs par celles de votre projet Firebase (voir le guide d'installation fourni séparément).
